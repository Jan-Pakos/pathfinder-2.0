Functional Requirements:
1. The system shall allow users to view all cities.
2. The system shall allow users to check if a route exists between two cities.
3. The system shall allow users to find the shortest route between two cities.
4. The admin shall be able to add new cities and connections between cities.
5. The system shall show users the mode of transportation for each connection in a route.


Happy Path:
1. User goes to /
2. The user selects two cities and checks if a route exists between them.
3. The system confirms that a route exists and displays the available routes.
4. The user selects a route and the system shows the mode of transportation for each connection in the route.
